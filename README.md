# Portafolio de Machine Learning & Data Science 

Bienvenido a mi portafolio analítico. Combino una sólida formación matemática y un enfoque estructurado para resolver problemas complejos, extraer patrones ocultos y traducir datos crudos en estrategias de negocio accionables y decisiones informadas.

## 🚀 Proyectos Destacados

### 1. [Predicción de Supervivencia: Análisis y Clasificación](./01_Clasificacion_Supervivencia_Titanic.ipynb)
* **Objetivo:** Construir un modelo predictivo para determinar tasas de supervivencia utilizando datos demográficos y socioeconómicos.
* **Algoritmos:** Árboles de Decisión (`DecisionTreeClassifier`).
* **Habilidades Aplicadas:** Limpieza de datos (manejo de valores nulos), ingeniería de características (transformación de texto a variables numéricas) y evaluación de precisión de modelos de Clasificación.

### 2. [Estimación de Valores Inmobiliarios: Regresión y Ensambles](./02_Regresion_Precios_Inmobiliarios.ipynb)
* **Objetivo:** Predecir el valor de mercado de propiedades inmobiliarias basándose en características espaciales, demográficas y económicas.
* **Algoritmos:** Bosques Aleatorios (`RandomForestRegressor`).
* **Habilidades Aplicadas:** Optimización de regresiones, análisis de importancia de variables (*Feature Importance*) para descubrir los factores que dictan el precio, y cálculo del Error Absoluto Medio (MAE).

### 3. [Segmentación de Consumidores: Aprendizaje No Supervisado](./03_Segmentacion_Clientes_KMeans.ipynb)
* **Objetivo:** Identificar perfiles ocultos de consumidores sin etiquetas previas para diseñar campañas de marketing hiper-segmentadas (ej. clientes premium vs. compradores impulsivos).
* **Algoritmos:** K-Medias (`KMeans`).
* **Habilidades Aplicadas:** Clustering geométrico, análisis de distancias espaciales, y visualización de datos estadísticos para la toma de decisiones estratégicas.
